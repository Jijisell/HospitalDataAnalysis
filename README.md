
# HospitalDataAnalysis

## Description
Mini-projet d'analyse de données de patients hospitaliers.

## Objectifs
- Charger un fichier CSV avec Pandas.
- Explorer les données.
- Calculer des statistiques descriptives.
- Compter les patients par sexe et par diagnostic.
- Visualiser l'âge et le cholestérol avec Matplotlib.

## Bibliothèques
- Pandas
- NumPy
- Matplotlib
- Jupyter

## Structure
- data/: fichier CSV des patients
- notebooks/: notebook d'analyse
- scripts/: scripts Python
